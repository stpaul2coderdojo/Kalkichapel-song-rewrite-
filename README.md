## 💎 Core Features

### 1. Quantum Hybrid File System (QHFS)
- **Hierarchical Quantum Storage Architecture**:
  - **Tier 0 (QRAM Superposition)**: Ultra-fast coherent quantum cache holding state vectors $|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$. Subject to physical decoherence ($T_2^* \approx 85\,\mu\text{s}$) stabilized by active surface-code error correction refreshes.
  - **Tier 1 (Entangled Nodes)**: Geographically distributed Bell pairs $|\Phi^+\rangle = \frac{|00\rangle + |11\rangle}{\sqrt{2}}$ maintaining entanglement teleportation channels with 99.84% verified fidelity.
  - **Tier 2 (Post-Quantum Cryo-NVMe)**: Permanent classical storage protected by CRYSTALS-Kyber-1024 and Dilithium-5 lattice proofs, immune to Shor's and Grover's quantum attacks.
- **Wavefunction Collapse Simulation**: Allows operators to "observe" files, collapsing quantum superpositions into classical eigenstates with probability distribution $P(|0\rangle) = |\alpha|^2, P(|1\rangle) = |\beta|^2$.

### 2. IPFS Planetary Storage & QCID Addressing
- **Quantum Content Identifier (QCID)**: Content-addressed hashing generating CIDv1 hashes (e.g. `bafy2bzace...`) based on file payload, quantum state coefficients, and Merkle leaf proofs.
- **Planetary Node Pinning**: Drag-and-drop file upload with custom multi-node pinning across 6 global quantum stations (Geneva, Svalbard, Tokyo, Atacama, Boulder, Singapore).
- **Quantum Bitswap Replication**: Replicate files across nodes with single-click pinning/unpinning, real-time node capacity telemetry, and local file payload export.

### 3. Earth Peace Quantum Cryptography (EPQC)
- **Interactive BB84 QKD Optical Simulation**:
  - Alice photon emitter sending bits across rectilinear (`+`) and diagonal (`×`) polarizations.
  - Bob detector measuring with random basis selection.
  - Sifting protocol discarding mismatched bases to generate an unconditionally secure symmetric key.
  - Real-time Quantum Bit Error Rate (QBER) calculation (healthy below 1.0%; eavesdropping alert triggered if QBER > 11.0%).
- **Lattice Cryptography Shield**: Dual-layer NIST Level 5 post-quantum encryption (Kyber-1024 KEM + Dilithium-5 digital signatures).

### 4. Carbon Credit Exchange & Planetary Tokenomics
- **Dual-Token Architecture**:
  - **EPQC**: Native utility and quantum staking coin used for QCF computation gas, storage rent, and node validator yields.
  - **CQB (Carbon Quantum Bond)**: Stablecoin mathematically pegged 1:1 to 1 metric ton of certified CO2 sequestered ($1\,\text{CQB} = 1\,\text{tCO}_2\text{e}$).
- **Automated Market Maker (AMM) DEX**: Instant swaps between EPQC and CQB with constant-product invariant $x \cdot y = k$.
- **Verifiable Carbon Retirement Engine**: Permanently retire credits from verified forestry, ocean kelp, and direct air capture projects, minting post-quantum cryptographic retirement receipts stored on QHFS.

### 5. Serverless Quantum Cloud Functions (QCF)
- **Serverless Quantum Runtime**: Execute quantum algorithms directly in-browser and simulate QPU execution with configurable shots (128 to 4096).
- **Pre-Built Quantum Routines**:
  - `Grover Search`: Quadratic speedup for unstructured carbon registry and collision search.
  - `QAOA Max-Cut`: Quantum approximate optimization algorithm for renewable grid distribution.
  - `VQE Molecular Ground State`: Variational Quantum Eigensolver simulating direct air capture catalyst chemical complexes.
  - `Quantum Entropy Beacon`: Pure, certified non-deterministic random numbers derived from qubit Hadamard measurements.

### 6. Gaia AI Quantum Copilot
- **Gemini-Powered Scientific Assistant**: Built-in intelligence assistant for quantum state analysis, post-quantum cryptography audit, and carbon portfolio rebalancing.

## 🚀 Getting Started

### Prerequisites
- Node.js >= 18.0.0
- npm or bun

### Installation

```bash
# Clone the repository
git clone https://github.com/your-org/quantum-hybrid-file-system.git
cd quantum-hybrid-file-system

# Install dependencies
npm install
```

### Environment Configuration

Create a `.env` file based on `.env.example`:

```bash
cp .env.example .env
```

```env
# GEMINI_API_KEY: Required for Gaia AI Quantum Copilot features
GEMINI_API_KEY=your_gemini_api_key_here
```

### Running Locally

```bash
# Start the development server (runs on port 3000)
npm run dev
```

Visit `http://localhost:3000` to access the application.

### Building for Production

```bash
# Type check and build static assets + bundled server
npm run build

# Start production server
npm run start
```
